# أذكاري — تطبيق أذكار واستغفار (PWA)

تطبيق ويب يتثبّت على الجوال كتطبيق، ويشتغل بدون إنترنت بالكامل (ما عدا الحلقات الجماعية).

## الميزات

- **الرئيسية:** بتعرض أذكار الصباح أو المساء تلقائياً حسب أوقات الفجر والظهر والعصر والمغرب لموقعك.
- **السبحة الذكية:** بتعدّ بالنقر، وفيها اهتزاز مع كل تسبيحة واهتزاز مزدوج عند إتمام الدورة. أهدافها 33 و100 و1000، وفيها 7 أذكار و"وضع الخشوع" الداكن.
- **أذكار الصباح والمساء:** 20 ذكراً لكل فترة، كل ذكر معه مصدره وفضله وعدّاده، مع التنقل التلقائي للذكر التالي وتكبير الخط.
- **الحلقات:** هدف استغفار جماعي، والمجموع بيظهر بدون أعداد فردية. بتحتاج Firebase.
- **زاوية تحفيظ القرآن:** فيها المصحف كامل بالرسم العثماني ومحفوظ داخل التطبيق، وتكرار الآية مع 7 قرّاء، وتسميع بثلاث طرق (إخفاء تدريجي، أول حرف، كلمة كلمة)، ومراجعة مجدولة بنظام التكرار المتباعد، وورد يومي، وخريطة للأجزاء الثلاثين.
- **إنجازي:** سلسلة الأيام، وخريطة استمرارية لآخر 12 أسبوعاً، وإحصائيات الشهر، والإعدادات.

## هيكل الملفات

```
index.html              الصفحة الرئيسية
manifest.webmanifest    بيانات التثبيت كتطبيق
sw.js                   العمل بدون إنترنت
css/                    التصميم والخطوط
js/app.js               الشاشات والتنقل
js/data.js              نصوص الأذكار ومصادرها
js/sun.js               حساب أوقات الصلاة
js/store.js             حفظ البيانات على الجهاز
js/challenge.js         الحلقات الجماعية (Firebase)
js/quran.js             زاوية التحفيظ
data/                   نص المصحف وبيانات السور والأجزاء
js/firebase-config.js   إعدادات Firebase
firestore.rules         قواعد حماية قاعدة البيانات
fonts/  icons/          الخطوط والأيقونات
```

## التجربة على الكمبيوتر

افتح مجلد المشروع في الطرفية وشغّل:

```
python -m http.server 8080
```

بعدين افتح في المتصفح:

```
http://localhost:8080
```

> التطبيق ما بيشتغل إذا فتحت `index.html` مباشرة بالضغط عليه. لازم يشتغل من سيرفر.

## النشر على GitHub Pages

1. اعمل مستودع جديد على GitHub، وارفع كل محتويات المجلد على مستوى الجذر.
2. من المستودع افتح **Settings** ثم **Pages**.
3. من **Source** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)`، واضغط **Save**.
5. بعد دقيقة بيصير الرابط شغّال، وبتقدر تفتحه من الجوال وتختار **إضافة إلى الشاشة الرئيسية**.

## تفعيل الحلقات الجماعية (Firebase)

1. افتح [console.firebase.google.com](https://console.firebase.google.com) واعمل مشروع جديد.
2. من **Build** ثم **Authentication** اضغط **Get started**، وفعّل طريقة الدخول **Anonymous**.
3. من **Build** ثم **Firestore Database** اضغط **Create database**، واختر **Production mode**.
4. افتح تبويب **Rules** في Firestore، واحذف المحتوى الموجود، وانسخ مكانه كل محتوى ملف `firestore.rules`، واضغط **Publish**.
5. من **Project settings** (الترس) انزل لـ **Your apps** واضغط أيقونة الويب `</>`، وسجّل التطبيق بأي اسم.
6. انسخ الكائن `firebaseConfig` اللي بيظهرلك، وحطه في ملف `js/firebase-config.js` مكان `null`، بالشكل هذا:

```js
export const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
```

7. من **Authentication** ثم **Settings** ثم **Authorized domains** أضف دومين موقعك على GitHub Pages:

```
USERNAME.github.io
```

8. لما تعدّل أي ملف بعد النشر، غيّر رقم الإصدار في أول سطر من `sw.js` عشان الجوالات تاخد النسخة الجديدة:

```
const VERSION = 'adhkari-v1.0.1';
```

## ملاحظات

- **البيانات:** كل العدّادات والإحصائيات محفوظة على جهاز المستخدم. السيرفر بيستقبل بس مجموع الحلقة، وآخر يوم شارك فيه العضو.
- **الاهتزاز:** بيشتغل على أندرويد، وما بيشتغل على آيفون لأن Safari ما بيدعمه.
- **أزرار الصوت:** ما بتنفع للعدّ لأن المتصفح ما بيقدر يقرأها. العدّ بيشتغل بالنقر، وبالمسافة وEnter والأسهم من لوحة المفاتيح أو خاتم تسبيح بلوتوث.
- **الموقع:** الأوقات محسوبة افتراضياً لغزة، والمستخدم بيقدر يحدد موقعه من الإعدادات.
- **نص المصحف:** من مشروع quran-json (المصدر QuranEnc) برخصة CC-BY-SA 4.0، والرخصة موجودة في `data/`.
- **صوت القرّاء:** من EveryAyah عبر Islamic Network (cdn.islamic.network)، وبحتاج إنترنت.
- **طريقة الحساب:** الفجر على زاوية 18°، والعصر على المذهب الشافعي (ظل الشيء مثله).
